# Meridian · 全球航贸工作台

## 设计概念
为外贸销售团队设计一张真正用于日常操作的航贸工作台：把客户国家、当前客户跟进和贸易单据连接成一条清晰的业务航线，让销售人员尽快看到可行动的下一步。

视觉参考可灵的电影级空间感和精致的视觉聚焦，转译到交易世界中的航线、目的市场与文件，而不复制其页面、品牌、文案或创作工具。工作台中唯一的电影感视觉是由当前可见的客户国家生成的路线；所有数据真实可追溯。已有全球发货地图仍展示真实运输记录。

## 令牌
- 港湾夜色 `#102942`：导航和航线画面。
- 航线蓝 `#286CFF`：主操作和焦点。
- 云雾工作区 `#EFF4F9`：长时间阅读的画布。
- 交易单据白 `#FFFFFF`：表格、表单和单据预览。
- 航期琥珀 `#B67532`：等待与临期状态；错误红仅用于明确异常。
- 石板墨 `#23364B`：文本、金额、交易对象。

中文使用现有系统字体，不加远程字体。表格数字使用等宽数值，长文本左对齐，金额右对齐。表面层级采用清晰的层线、局部深色地图及少量投影，避免给每一行数据再套一个卡片。

## 布局
固定港湾蓝导航、顶部全局搜索与面包屑、原有工作页签、真实数据工作区。首页按“业务航线 → 当期经营判断和指标 → 线索漏斗 → 今日执行”排列，目的地由登录账号当前可见客户的 `country` 字段定位；未识别目的地不放置在地图，空数据时明确说明。

```
┌ 深海导航 ┬ 面包屑 / 搜索 / 已打开页面 / 用户 ─────┐
│ 工作台   │ 今天的业务             时间 / 晨会视图  │
│ 客户线索 │ 上海 → 真实客户目的市场                 │
│ 销售管道 ├────────────────────┬───────────────────┤
│ 贸易单据 │ 经营判断 / 指标      │ 真实线索漏斗     │
│ 知识设置 │ 待办与交易阶段       │ 后续工作队列     │
└──────────┴────────────────────┴───────────────────┘
```

## 保真边界
原有身份验证、用户保存的主题偏好、权限控制、业务模块、DOM 接口和单据打印规则保持不变。只有没有显式用户主题时才将“航线 Trade”作为默认主题；已有主题记录继续优先。人物素材仅作为品牌陪伴形象，而非用户头像或 CRM 客户。

## 前端分层
- `src/trade-workspace.ts`：壳层行为（抽屉导航、⌘K 命令面板、工作台航线图、面包屑/标题同步）。
- `src/trade-workspace.css`：基础令牌与导航/顶栏/登录骨架。
- `src/trade-overhaul.css`：第一轮全量重制（工作台重排、组件语言、响应式断点 1500/1180/900/640）。
- `src/trade-polish.css`：第二轮统一打磨（页头、工具栏、表格、徽章、抽屉/弹窗、空状态、触控尺寸）。
  贸易单据预览纸面（`.doc-paper`）是打印表面，通用表格样式一律用 `:not(.doc-paper *)` 排除。
  `#customerBulkToolbar`（`.toolbar`）与 `.lead-filter-row` 不加盒化样式：快捷联系条必须贴住其右端（≤2px 契约）。
