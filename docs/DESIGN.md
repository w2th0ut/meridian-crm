# 客多多 Keduoduo · 外贸客户经营台

## 设计概念

外贸业务员每天面对的不是"仪表盘"，而是一叠单据、一本客户账，和一个随时会变的下一步。
客多多把这套工作语言直接搬进界面：**纸（单据纸白）· 墨（通栏与正文）· 印章红（唯一的动作色）**。

视觉依据来自中国外贸的真实材料：报关单与发票的纸stock、单据台账的细线与分栏、合同与发票上的
公司印章。界面上唯一的高饱和色是印章红，它只出现在三处——品牌章、当前所在、这一屏最该点的那个按钮，
别处一律墨与纸。这样屏幕安静，红色才说得上话。

刻意不做的：不套 SaaS 白卡 + 圆角 + 柔阴影的通用组件库外观；不用杂志式细密多栏；不用全大写小标题
做装饰；不用等宽字体假装"技术感"；不在标题里单独把一个词换成别的颜色。

## 令牌

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 纸（画布） | `#F1F2EE` | 冷调纸白，比暖奶油色更接近单据纸，长时间看不发黄 |
| 叶（面板） | `#FFFFFF` | 工作区、表格、浮层 |
| 墨（正文/通栏） | `#16191B` | 中性近黑；页首通栏、主按钮文字、打印感表头 |
| 石墨（次级文字） | `#5D666B` | 说明、标签、时间 |
| 线（分隔） | `#D9DDD6` | 1px，只在需要编码结构时出现 |
| 印章红（动作） | `#CC2118` | 主按钮、当前项竖标、品牌章、最大市场 |
| 玉（成交/健康） | `#10654E` | 已成交、健康度 |
| 琥珀（等待/风险） | `#9E5F17` | 临期、待确认 |

主题换肤仍然生效：印章红取 `--brand`，用户自定义主题会同时改变印章色。

## 版式

- 单一字族：`PingFang SC / Hiragino Sans GB / Source Han Sans SC / Noto Sans CJK SC / Microsoft YaHei`。
  私有化部署不引远程字体，性格来自字重与尺度的对比，而不是换字体。
- 尺度：通栏标题 26px/800（-0.045em）；判断句 25px/800；单据数值 22–30px/750 且 tabular-nums；
  正文 12–13px/1.65；标签 10.5–11px/600（letter-spacing .05em，不用全大写）。
- 行宽控制在 62–68ch。

## 布局

```
┌ 纸色导轨 ┬ 面包屑 · ⌘K · 已开页面 · 账号 ─────────────────────┐
│ ▌客多多  │ ██ 墨色通栏：页面名 26px / 一句话目的 / 右侧动作+日期 ██ │
│  工作台  ├─────────────────────────────────────────────────────┤
│  贸易单据 │  起运 上海   DE 5 │ US 1 │ JP 1 │ SE 1 │ AE 1        │  ← 唛头带
│  自动获客 │  5 个市场 · 11 家客户                    [客户][航线][开单据] │
│  …       ├──────────────────────────┬──────────────────────────┤
│  客户管理 │ 当前判断 + 四项指标        │ 线索漏斗（细线台账）        │
│  业务工具 │ 跟进队列 / 管道健康        │                          │
└──────────┴──────────────────────────┴──────────────────────────┘
```

- **墨色通栏**是全站统一的页首：白标题 + 一句话目的 + 该页动作。它是这套设计记人的地方，
  也替代了原来"卡片里再放标题"的层级重复。
- **唛头带**替代原来的深蓝航线插画：每个目的市场一枚唛头（国家代码 + 客户数 + 名字），
  按客户数排序，最大的一枚用印章红。数据仍来自当前账号可见客户的 `country` 字段，不臆造记录。
- 正文用**单据分栏**：1px 线分隔、零圆角、零阴影；表格表头用墨线收口；空状态像一张空白单据。
- 侧栏是纸色导轨：当前项用 3px 印章红竖标 + 白底，不做蓝色药丸。

## 动效（代码实现，`frontend/src/trade-motion.ts`）

动效全部由 TypeScript 驱动，CSS 不承担动画：

| 动效 | 实现 | 时机 / 参数 |
| --- | --- | --- |
| 航线描出 | SVG `path` + WAAPI 的 `strokeDashoffset` | 620ms，逐条错开 55ms，从「起运 上海」到每枚唛头 |
| 唛头盖下 | WAAPI `translateY(-7px) scale(.97)` → 回弹 1.015 → 落位 | 300ms，按名次错开 55ms（90/145/200/255/310ms） |
| 数量计数 | `requestAnimationFrame` + easeOutCubic | 520ms，与对应唛头同步起动 |
| 页首落位 | WAAPI 位移 9px + 淡入 | 240ms，仅在用户切换页面时 |

工程约束（已写入 `src/self-test.ts` 防回退）：

- **只播一次**：以市场数据签名去重；工作台每 60 秒轮询重渲染时只做静态重绘，不重播入场。
- **可取消**：模块持有全部 `Animation` 与 rAF handle，重入前 `cancel()`，避免叠加。
- **不叠加**：航线层每次重绘先 `replaceChildren()`，尺寸变化只静态重画（resize 去抖 140ms）。
- **降级**：`prefers-reduced-motion: reduce` 时零动画，直接落到终态（航线静态虚线、数字为终值）。
- 观察者效应：不做滚动揭示、不给每张卡加 hover 抬升；动效只服务一次入场与用户动作。

## 保真边界

鉴权、权限、业务接口、DOM 契约、单据打印规则不变。三层样式文件收敛为单一
`frontend/src/theme-keduoduo.css`（行为仍在 `trade-workspace.ts`）。两条必须守住的契约：

1. 贸易单据纸面 `.doc-paper` 是打印表面，通用表格样式一律 `:not(.doc-paper *)` 排除。
2. `#customerBulkToolbar`（`.toolbar`）与 `.lead-filter-row` 不加盒化样式——快捷联系条要贴住它们右端（≤2px）。
3. 详情抽屉可盖内容，但不可盖导航：抽屉打开时侧栏 z-index 抬到遮罩之上。

## 系统后台 = 控制台（`theme-keduoduo-admin.css` + `admin-deck.ts`）

后台和业务区是两种活儿：业务区在**读单据**，后台在**检查与开关**。所以后台不用纸白，
改用深色甲板 + 信号灯——短时、高频、要一眼看出"哪里开着、哪里危险"。

| 项 | 做法 |
| --- | --- |
| 甲板 | `#101315` 底 + 44px 细坐标网格；面板 `#181c1e`、线 `#2a3134`、零圆角 |
| 信号 | 玉 `#4FA98A` 正常/已授权 · 琥珀 `#C98A3C` 待确认 · 印章红 `#E0483A` 需处理/全公司范围 |
| 页首 | 不再用墨色通栏，改为"立起来的信号条"：左侧 3px 红色渐变竖标 + 白色 25px/800 标题 |
| 状态带 | 每页顶部 `kd-rail`：本页关键读数（角色/权限/已授权/全公司范围/服务与队列），数据全部取自当页 DOM 与 `/api/health`，取不到就不显示 |
| 仪表盘化 | 设置页开关做成闸刀；数据库进度、日志筛选、主题色卡、审批流程库全部落甲板配色 |
| 授权矩阵带 | 每条权限旁 5 段刻度（未授权→仅本人→本组→本组及下级→全公司），由 `select` 真实值驱动；改选择即时更新刻度与顶部读数 |
| 危险提示 | "全公司范围"条数单独计数；超过 0 时状态带亮起红色信标（呼吸 2.4s，`prefers-reduced-motion` 关闭） |

工程约束（写入 `src/self-test.ts`）：

- 后台视图分布两处（`.workspace > .view` 与 `main > .view`），激活判定必须同时覆盖。
- 状态带每页**只允许一条**：每次同步先清理多余节点（早期用 `:scope >` 查找导致重复插入 15 份，已修）。
- 状态带必须紧随页首；首次挂载早于权限页渲染时，之后要"搬正"位置。
- 刻度与读数在用户改授权范围时即时刷新（60ms 去抖），不等 MutationObserver。
- 移动端：状态带降为 1 列，刻度带隐藏（下拉框本身已够读）。

## 跟进船期表（`trade-timetable.ts` + `.kd-board`）

工作台首屏不再是卡片堆，而是一张**横向排期板**——外贸的日课是排期：什么时候联系谁。

```
┌ 2 已逾期 ┬ 27 今天 ┬ 28 周三 ┬ 29 周四 ┬ 30 周五 ┬ 31 周六 ┬ 1 周日 ┬ 2 周一 ┬ 1 未排期 ┐
│ 10:30    │ 10:30   │ 10:30   │ 无排期   │ 10:30   │ 无排期   │ 无排期  │ 10:30   │ —      │
│ 认证资料 │ 报价跟进 │ 样品确认 │          │ 合同回签 │          │        │ 年度协议 │ 补考提醒│
└──────────┴─────────┴─────────┴─────────┴─────────┴─────────┴────────┴─────────┴────────┘
   ↑ 逾期闸口（印章红）   ↑ 今天：唯一的墨底列 = 页面焦点
```

- 四段归位：**已逾期**（早于今天）／**今天起七天**／**未排期**（无到期日，不编造时间）。
- 每列：日期大字（27px/750 tabular）+ 星期 + 条数；事件行 = 时间 + 标题，高优先级带印章红点。
- 点击事件 → 跳到待办中心；该行若在当前筛选里则滚过去高亮（1.6s 脉冲），
  不在就停在列表顶部——**不猜测筛选口径**（试过自动切「逾期」，但该筛选口径与到期日无关，会把人带到空列表）。
- 数据只来自 `todos[].dueAt`；完成的不显示。窄屏转为横向吸附滚动（`scroll-snap: x`）。
- 与既有契约无冲突：只**新增**一块，未改动任何被测试断言的节点。
